# Small Business Network Design

## Project Overview

This project presents a network infrastructure design for a small business environment.

The objective is to develop a reliable, secure and scalable network that supports everyday business operations, including internet access, communication, file sharing and wireless connectivity.

The design applies practical networking concepts to the infrastructure requirements of small organizations.

## Project Objectives

- Design a structured Local Area Network (LAN)
- Plan IP addressing and subnet allocation
- Establish wired and wireless connectivity
- Identify suitable networking equipment
- Incorporate basic network security
- Support multiple users and devices
- Consider future business expansion
- Develop a practical network troubleshooting approach

## Proposed Network Architecture

The network design uses a centralized architecture connecting business devices through networking equipment.

### Main Components

- Internet connection
- Router and firewall
- Network switch
- Wireless access points
- Employee workstations
- Shared printers
- Optional server or network storage

### Network Structure

Internet → Router/Firewall → Network Switch → Connected Devices

Wireless access points connect to the network to provide Wi-Fi coverage for authorized devices.

## IP Addressing Plan

The proposed network uses private IPv4 addressing.

An example addressing structure is:

| Device/Network | IP Address |
|---|---|
| Network | 192.168.10.0/24 |
| Router/Gateway | 192.168.10.1 |
| Network Switch | 192.168.10.2 |
| Wireless Access Point | 192.168.10.3 |
| DHCP Client Range | 192.168.10.100–192.168.10.200 |

This addressing plan is illustrative and can be adjusted according to organizational requirements.

## Wireless Network Design

The wireless network is intended to provide reliable connectivity throughout the business premises.

Design considerations include:

- Access point placement
- Wireless coverage
- Signal interference
- Network capacity
- Wi-Fi security
- Guest network separation

## Network Security

The proposed security measures include:

- Strong administrative passwords
- WPA2/WPA3 wireless encryption
- Firewall configuration
- Guest network isolation
- Restricted administrative access
- Regular firmware updates
- Device access management
